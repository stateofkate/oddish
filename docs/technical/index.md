# Engineering reports

This section holds internal engineering reports from the Oddish and sandbox teams: system designs, rollout results, cost measurements and service levels. It is for Abundant staff. Customer guides live in the Oddish section.

Pages come in two forms. Most are plain text, like this one. Pages with drawings and charts are designed documents; they open in place, and a "Text version" link at the top gives the same conclusions as text, which is also what search finds.

Numbers are given as percentages first, with the denominator named next to them, and dollars second. A report is a snapshot of its stated date, not a live dashboard.

## Sections

- [Sandboxes](sandboxes/overview.md): where trials run, which provider runs what, and the oddish-mon work that moved trial supervision inside the sandbox.

Reports are Markdown under this folder; a designed page is an HTML file under `assets/reports/` with a Markdown twin of the same slug.
